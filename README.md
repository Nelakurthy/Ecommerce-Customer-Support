My Customer Support Chatbot is a web-based application developed using Python, Django, HTML, CSS, JavaScript, and MySQL. The user first opens the chatbot interface and enters a customer-support question, such as asking how to reset a password. When the user submits the question, the request is sent to the Django backend through the URL routing system. The corresponding view in `views.py` processes the user's question and generates an appropriate response, which is then displayed back on the chat interface. The conversation details, including the user's message and chatbot response, are stored in the MySQL database using Django ORM. The project also includes a history feature, where the user can click the History option to retrieve previous conversations from MySQL through Django views and display them on the webpage. This flow connects the frontend, Django backend, and MySQL database to provide an interactive customer-support system.
